# 05 — SageMaker Built-In Algorithms

## 🎯 Engineering Objective

Develop practical decision-making skills for selecting and applying
Amazon SageMaker built-in algorithms to solve machine learning problems
efficiently without unnecessary custom model development.

This section emphasizes pragmatic ML engineering: choosing reliable,
managed solutions that accelerate experimentation and deployment.

---

## 🧠 Capabilities Developed

- Selecting appropriate SageMaker built-in algorithms based on problem type
- Understanding training input modes and operational constraints
- Applying managed algorithms across NLP, vision, forecasting, anomaly detection, and classical ML tasks
- Evaluating tradeoffs between managed algorithms and custom training workflows
- Designing faster experimentation pipelines using AWS-native tooling

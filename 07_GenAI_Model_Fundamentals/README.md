# 07 — Generative AI Model Fundamentals

## 🎯 Engineering Objective

Develop a solid conceptual foundation for transformer-based models and
large language models (LLMs), enabling informed design decisions rather
than trend-driven implementation.

This section focuses on understanding how generative models work and how
they are applied within practical ML engineering workflows.

---

## 🧠 Capabilities Developed

- Understanding transformer architecture and attention mechanisms
- Working with tokens, embeddings, and generation parameters
- Distinguishing fine-tuning, transfer learning, and prompt-based adaptation
- Connecting theoretical concepts to hands-on notebook experimentation
- Understanding how AWS integrates and operationalizes foundation models

---

## ☁️ AWS Services & Concepts Covered

### Generative Model Fundamentals
- Transformers and attention mechanisms
- Tokenization and embeddings
- Sampling parameters (e.g., temperature)

### Model Adaptation
- Fine-tuning vs transfer learning strategies

### AWS GenAI Tooling
- SageMaker notebook workflows
- SageMaker JumpStart
- Hugging Face integrations on AWS

## 🔗 Role in ML Engineering Workflow

Generative AI fundamentals support:

- informed selection of foundation models
- responsible model adaptation strategies
- integration of LLMs into production ML systems
- downstream applications such as RAG and agent-based workflows
